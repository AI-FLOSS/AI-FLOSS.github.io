title: Get involved

AI-FLOSS is just getting started, which makes this the best time to help shape it.

## Bring a project

Maintain an open source project that welcomes AI-assisted contributions? Suggest it for
[Awesome AI-FLOSS](/awesome) and help shape the shared practices.

Built something with AI that you'd like others to use and improve? Before it becomes another
one-person project, consider bringing it into the AI-FLOSS organisation, where more people can
maintain it. And before starting something new, check whether an existing project could take your
idea as a plugin or a setting instead.

## Join the discussion

Disclosure formats, agent guidelines and review workflows are open questions, and we want many
voices on them.

- [GitHub Discussions](https://github.com/orgs/AI-FLOSS/discussions): ideas, questions and longer
  conversations that should stay findable.
- [#ai-floss:matrix.org](https://matrix.to/#/#ai-floss:matrix.org): the main AI-FLOSS channel on Matrix.
- [#ai-floss-general:matrix.org](https://matrix.to/#/#ai-floss-general:matrix.org): general chat.

For concrete proposals, open an issue on [GitHub](https://github.com/AI-FLOSS/AI-FLOSS.github.io/issues).

## Build the tooling

Templates, review bots, CI recipes and documentation all need hands, human and otherwise. Browse
the repositories at [github.com/AI-FLOSS](https://github.com/AI-FLOSS).
