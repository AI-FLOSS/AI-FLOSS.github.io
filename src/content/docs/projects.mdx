## Anthem

[![AI readiness](https://img.shields.io/endpoint?url=https://ai-floss.github.io/badges/AI-FLOSS/Anthem.json)](/guidelines/readiness/)

**A desktop music player with a real library engine.** Anthem keeps gmusicbrowser's data model and
power, with a user interface people can re-layout and re-skin. A track is a piece of music, not a
file: it survives renames, moves, format changes and retagging, so your ratings and play history
never get lost.

Anthem is our flagship project and is in early development. The library core, query engine,
playback and gmusicbrowser import work; tag writing and media keys are still to come.

[Source code](https://github.com/AI-FLOSS/Anthem) · GPL-3.0-or-later ·
[Contribute](https://github.com/AI-FLOSS/Anthem/blob/main/AGENTS.md)

## ai-readiness

[![AI readiness](https://img.shields.io/endpoint?url=https://ai-floss.github.io/badges/AI-FLOSS/ai-readiness.json)](/guidelines/readiness/)

**Scores how ready a repository is for AI-assisted development.** A command-line tool, library and
GitHub Action that checks any public repository against the eight
[AI Readiness Score](/guidelines/readiness/) checks and shows the evidence for each.

[Source code](https://github.com/AI-FLOSS/ai-readiness) · MIT ·
`npx github:AI-FLOSS/ai-readiness owner/repo`
